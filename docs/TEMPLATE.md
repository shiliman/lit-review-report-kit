# 课程模板规格

这份文档记录工具默认对齐的版式参数。**换学校、换模板时，先改这里，再改 `litreport/docx_kit.py`**，
两边对不上就会出现「代码改了文档没改」的漂移。

## 常见返工点

1. **页码是域不是文本框**：`docx_kit` 用 `PAGE` 域，Word 打开会自动更新；用 WPS 时若显示 1 不变，
   按 `Ctrl+A` → `F9` 更新域。
2. **三线表的线宽**：Word 里 1.5 pt 常被默认表样式覆盖，需要用 `w:tblBorders` 显式写，代码里已处理。
3. **中文引号**：正文里的 `“”` 必须用中文全角，用半角会在部分字体下渲染成直引号。
4. **英文文献的作者**：GB/T 7714 要求姓全大写、名缩写，请直接把作者写成 `WANG C`（姓 + 空格 + 名首字母）这种形式；
   工具只在「首词已全大写」时原样保留，其余情况按「名 姓」拆分——英文姓名顺序本身有歧义，不要指望它替你判断。
   中文作者写 `王晨宇` 即可，三位以上会自动加「等」。
